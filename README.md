## What is CITHUB?

**CITHUB** is a lightweight, self-hosted Git platform built for developers who want full control over their code hosting infrastructure. It is a customized fork of [Gitea](https://gitea.io) (v1.26.0-dev), featuring a premium dark UI redesign with violet/blue accent gradients, deep black backgrounds, and modern typography.

CITHUB provides:

- **Repository Hosting** — Create, manage, and collaborate on Git repositories
- **Issue Tracking** — Track bugs and feature requests with labels, milestones, and assignments
- **Pull Requests** — Code review workflows with diff viewing and merge controls
- **CI/CD (Actions)** — Built-in continuous integration compatible with GitHub Actions workflows
- **Package Registry** — Host your own packages (npm, PyPI, Docker, Maven, and more)
- **Wiki** — Built-in documentation wiki for every repository
- **Organizations & Teams** — Manage access with fine-grained permissions
- **Web-based Code Editor** — Edit files directly in the browser
- **API** — Full REST & Swagger API for automation

## Quick Start

### 1. Clone the Repository
```bash
git clone <your-repo-url> cithub
cd cithub
```

### 2. Build Frontend Assets
```bash
make frontend
```

### 3. Build the Backend Binary
```bash
TAGS="bindata sqlite sqlite_unlock_notify" make backend
```

### 4. Rename the Binary (optional)
```bash
mv gitea cithub
```

### 5. Start the Server
```bash
./cithub web
```

### 6. Open in Browser
Navigate to [http://localhost:3000](http://localhost:3000) and complete the initial setup.

## Configuration

The main configuration file is located at `custom/conf/app.ini`. Key settings:

```ini
[server]
HTTP_PORT        = 3000
ROOT_URL         = http://localhost:3000/
DOMAIN           = localhost

[database]
DB_TYPE  = sqlite3
PATH     = data/gitea.db

[repository]
ROOT = /path/to/gitea-repositories

[security]
INSTALL_LOCK = true
SECRET_KEY   = <auto-generated>
```

## Customization

### Modifying the Theme
Edit `web_src/css/zorphix.css` to change colors, then rebuild:
```bash
make frontend
TAGS="bindata sqlite sqlite_unlock_notify" make backend
```

### Template Overrides (Hot Reload)
Place modified `.tmpl` files in `custom/templates/` matching the original path. Changes take effect on server restart without recompiling.
